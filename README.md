Baby Photoshop is a simple **C++ image processing project** that allows users to apply a variety of filters and transformations to images.  
It provides a **menu-driven interface** for experimenting with pixel manipulation techniques, making it a great introduction to image processing concepts.  

---

## 🚀 Features
- Grayscale filter  
- Black & white conversion  
- Invert colors  
- Rotate / flip image  
- Blur and sharpen filters  
- Edge detection  
- Merge two images  
- Save the processed image
